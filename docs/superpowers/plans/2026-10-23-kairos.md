# kairos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go library that lands an HTTP request at, or just after, a target instant on a remote server's clock, using calibrated, staggered, precisely released workers.

**Architecture:** Pure math lives in `estimate.go` (turning measurements into a `stampDelay` estimate and combining sources) and `schedule.go` (fire times plus the spread). A `Session` owns one warm `http.Client` per worker. `Calibrate` measures the target (with a precise stamp or a `Date` sweep), plus an optional reference clock. `Fire` runs the workers, which a single releaser goroutine releases at their fire times. `Run` = `New` + wait + `Calibrate` + `Fire`.

**Tech Stack:** Go 1.26, standard library only (`net/http`, `net/http/httptest` for tests).

**Spec:** `docs/superpowers/specs/2026-10-23-kairos-design.md`

## Global Constraints

- Module `github.com/jamesgarfield/kairos`, package `kairos`, `go 1.26` in go.mod. Standard library only.
- HTTP/HTTPS only.
- Each worker owns a dedicated keep-alive connection: its own `*http.Transport` with `MaxIdleConnsPerHost: 1`, `IdleConnTimeout: 5 * time.Minute`, `DisableCompression: true`.
- Never call `os.Exit`, `log.Fatal*`, or `panic` for runtime conditions. Never write files. Return errors. `fmt.Fprintf` write errors may be ignored.
- No disk I/O, logging, or lock contention between a worker's release and its `client.Do`. Attempts are buffered in per-worker slices and logged only after the run.
- At most one goroutine busy-waits at a time (the releaser). Retries never spin.
- No new sends after the deadline. Requests in flight get `InFlightGrace`, then they're cancelled.
- Defaults: Workers 8, Spacing 5ms, CalibrationRounds 10, RewarmBefore 150ms, Spin 2ms, GiveUp 2s, CalibrateBefore 30s, InFlightGrace 500ms, RequestTimeout 5s, SweepStep 2ms, MaxBodyBytes 1 MiB, Lead = 3× calibrated RTT when 0.
- Before Task 1: `git checkout -b kairos-lib` and commit the spec and this plan (`docs: add kairos design and plan`). Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **The target is too close or already past.** `Fire` must return `ErrTooLate` (wrapped, saying how late) and must not send anything. `Run` must calibrate immediately when `Target - CalibrateBefore` has already passed. Tests go in Tasks 8 and 9.
2. **Before the target, the endpoint answers non-2xx** (403 "not open yet"). Calibration must still succeed, because status is ignored there. Fire must retry those attempts as non-hits and hit on the first 2xx at or after the target. Tests go in Tasks 7 and 8.
3. **The response has no usable `Date` header or body time** (stripped by a proxy, or an unparsable body). Calibration returns an error naming the round or sample. Nothing hangs. Test goes in Task 7.
4. **The caller cancels `ctx` mid-fire.** `Fire` returns promptly (within 200ms) with the partial `Result` and `ctx.Err()`. Test goes in Task 8.
5. **A slow endpoint is still in flight at the deadline.** If it completes within `InFlightGrace` it is recorded (it may have been acted on), and nothing is *sent* after the deadline. Test goes in Task 8.

### Task 3: Estimation math (pure)

**Files:**
- Create: `estimate.go`
- Test: `estimate_test.go`

**Interfaces:**
- Consumes: `Estimate`, `Source`, `Policy` (Task 1).
- Produces:
```go
const preciseThreshold = 10 * time.Millisecond // extractor precision <= this ⇒ precise method
func quantile(d []time.Duration, q float64) time.Duration   // sorted copy, index round(q*(n-1)); 0 for empty
type sweepSample struct{ Sent time.Time; Stamp time.Time; RTT time.Duration }
func preciseEstimate(delays []time.Duration) Estimate          // Point=q.5, Lo=q.1, Hi=q.9, SourcePrecise
func sweepEstimate(samples []sweepSample, precision time.Duration) Estimate
func referenceEstimate(offset time.Duration, rtts []time.Duration) Estimate // Point=offset+q.5/2, Lo=offset+q.1/2, Hi=offset+q.9/2, SourceReference
func combine(target Estimate, ref *Estimate, p Policy) (final Estimate, disagreement time.Duration)
```

**The sweep algorithm.** The server stamp is truncated to `precision`, so each sample constrains `D` to `[Stamp−Sent, Stamp+precision−Sent)`.
1. Drop samples whose RTT is more than 2× the median RTT. These are cold connections and outliers.
2. Let `J = (q.9(RTT) − q.1(RTT)) / 2`.
3. Set `Lo = max(lower bounds) − J` and `Hi = min(upper bounds) + J`. If `Lo > Hi`, swap them.
4. `Point = Lo + (Hi−Lo)/2`, `Source = SourceSweep`.

**The `combine` rule.**
- Let `c = clamp(ref.Point, target.Lo, target.Hi)`. Then `disagreement = ref.Point − c`, or 0 when `ref == nil`.
- With `ref == nil`, the result is `target`, whatever the policy.
- `PolicyInterval`:
  - If `disagreement == 0`, the result is `Estimate{SourceReference, ref.Point, max(ref.Lo, target.Lo), min(ref.Hi, target.Hi)}`.
  - Otherwise it's `Estimate{target.Source, c, target.Lo, target.Hi}`.
- `PolicyReferenceWins` returns `*ref`.
- `PolicyTargetWins` returns `target`.

### Task 4: Schedule with spread, and server-time estimation (pure)

**Files:**
- Create: `schedule.go`
- Test: `schedule_test.go`

**Interfaces:**
- Consumes: `Estimate`, `Schedule`, `Attempt`, `ServerTime`, `preciseThreshold`.
- Produces:
```go
func plan(target time.Time, final Estimate, workers int, spacing, lead, giveUp time.Duration) Schedule
func estimateServerTime(a Attempt, stampDelay time.Duration) time.Time
```

**The `plan` rule.**
- `ideal = target − Point`.
- `first = min(ideal − lead, target − Hi)`. This leans early.
- `latest = target − Lo`.
- `eff = spacing`. If `workers > 1` and `first + (workers−1)·spacing < latest`, then `eff = latest.Sub(first) / (workers−1)`.
- `FireAt[i] = first + i·eff`.
- `Deadline = latest + giveUp`.

**The `estimateServerTime` rule.**
- If the attempt has a non-zero `Server.Time` with `Precision <= preciseThreshold`, return `Server.Time`.
- Otherwise `e = Sent + stampDelay`. If `Server.Time` is non-zero, clamp `e` to `[Server.Time, Server.Time + Precision − 1ns]`.

### Task 7: Calibrate

**Files:**
- Create: `calibrate.go`
- Test: `calibrate_test.go`

**Interfaces:**
- Consumes: `send`, `preciseEstimate`, `sweepEstimate`, `referenceEstimate`, `combine`, `quantile`, `sleepUntil`, `runReleases`, `measureWakeLatency`, `ReferenceClock`.
- Produces: `func (s *Session) Calibrate(ctx context.Context) (Calibration, error)`

**Behavior.** Each calibration request uses `context.WithTimeout(ctx, RequestTimeout)`, the `Calibration` RequestFunc, and the `CalibrationServerTime` extractor. Status is ignored. Any `Attempt.Err` aborts calibration.
1. **Probe:** one request on client 0. If its `Server.Precision <= preciseThreshold`, use the precise method. Otherwise use the sweep.
2. **Precise method:** `CalibrationRounds` rounds. In each round, every client sends at the same time. Collect `Server.Time − Sent` and the RTT. Errors are wrapped `"calibration round %d: %w"`. The result is `Target = preciseEstimate(delays)`.
3. **Sweep method** (P = precision):
   - **Coarse pass:** 10 samples released via `runReleases` at `now+50ms + i·P/10`, each on its own goroutine using client `i % Workers`. That gives `e1 = sweepEstimate(...)`.
   - **Fine pass:** let `D = e1.Point` and pick the first server boundary `k·P` (absolute, with `time.Truncate(P)` arithmetic) whose local send instant `k·P − D` is later than `now+50ms`. Set `step = max(SweepStep, (e1.Hi−e1.Lo)/50)` and `m = min(25, ceil((e1.Hi−e1.Lo)/2/step)+1)`. Send samples at `(k·P − D) + j·step` for `j ∈ [−m, m]`, released the same way.
   - `Target = sweepEstimate(coarse ∪ fine)`. Errors are wrapped `"calibration sweep sample %d: %w"`.
4. `RTT` = the median RTT across all calibration samples (for the sweep, after the same 2×-median filter).
5. If `Reference != nil`, call `ref := referenceEstimate(Reference.Offset(ctx), rtts)`. Its errors are wrapped `"calibration reference: %w"`.
6. Combine: `Final, Disagreement = combine(Target, ref, Policy)`. If `Disagreement != 0`, call `Logger.Logf` with both estimates.
7. Set `WakeLatency = measureWakeLatency(20)` and `TakenAt = time.Now()`.

### Task 8: Fire

**Files:**
- Create: `fire.go`
- Test: `fire_test.go`

**Interfaces:**
- Consumes: `Calibration`, `plan`, `estimateServerTime`, `runReleases`, `sleepUntil`, `send`.
- Produces:
```go
func (s *Session) Fire(ctx context.Context, cal Calibration) (Result, error)
func defaultHit(target time.Time) func(Attempt) bool // Err == nil && 200 <= StatusCode < 300 && !Estimated.Before(target)
```

**Behavior.**
1. Set up the schedule:
   - `lead = cfg.Lead`, or `3·cal.RTT` if that is zero.
   - `sched = plan(Target, cal.Final, Workers, Spacing, lead, GiveUp)`.
   - If `sched.FireAt[0]` is not after `time.Now()`, return `Result{...}` and `fmt.Errorf("%w: first worker would fire %v ago", ErrTooLate, …)` without sending anything.
2. Set up the contexts:
   - `sendCtx` = deadline `sched.Deadline` on `ctx`. A first hit also cancels it when `StopOnFirstHit` is set.
   - `reqCtx` = deadline `sched.Deadline + InFlightGrace` on `ctx`. Every request uses `reqCtx`.
3. Start one `runReleases` goroutine with one release per worker at `FireAt[i]`, spinning `Spin` and correcting by `cal.WakeLatency`.
4. Each worker goroutine:
   - Sleeps (a timer, no spin) until `FireAt[i] − RewarmBefore`, if that is still in the future.
   - Sends one rewarm request (the real `Request`, with a `RequestTimeout` ctx). A failure goes to `Logger.Logf` and isn't recorded.
   - Prebuilds its first request.
   - Waits on its release channel or `sendCtx.Done()`.
   - Then loops: break if `sendCtx` is done or `time.Now()` is not before `Deadline`. Otherwise send, then set `N`, `Worker`, `Estimated = estimateServerTime(a, cal.Final.Point)` and `Hit = isHit(a)`, and append to a slice preallocated with capacity 64. On a hit, call `cancelSend` if `StopOnFirstHit`, then break. Requests after the first are built inside the loop, and a build error is recorded as an Attempt with `Err`.
5. After every worker is done, `Best` = the hit with the earliest `Estimated` (pointer into `Attempts`). Fill in `Target`, `Calibration`, `CalibrationAge` (measured at Fire start) and `Schedule`.
6. Return values:
   - If `ctx.Err() != nil`, return the result and `ctx.Err()`.
   - If `Best == nil`, return the result and `ErrNoHit`.
   - Otherwise return the result and nil. Log the best hit through `Logger`.

func Run(ctx context.Context, cfg Config) (Result, error) // New; defer Close; sleepUntil(Target-CalibrateBefore, 0) if in future; Calibrate; Fire

There is no built-in log format. `Result` is the consumer's log: each `Attempt` and `Schedule.FireAt[a.Worker]` together carry everything the old TSV had (worker, attempt number, fire time, sent, received, RTT, server time, delta vs target via `Estimated.Sub(Target)`, error), plus status, estimate and hit. Pre-target attempts are included. Text messages during a run go through `Logger`, never from inside the send loop.
